System Version 2.1.0

🚀 Major Updates (v2.1):

  • 🛡️ Smart Audit Logs: Complete system-wide tracking. Every "Create," "Edit," and "Approval" now logs exactly what changed (e.g., "RAM: 4GB → 8GB").
  • 🔍 Smart Search: Added Smart Asset Search to filter stock by specific specs (SSD, CPU, etc.) and a powerful Global Search for Suppliers & Repairs.
  • ⚡ Approval System: Admins can now see a "Diff" view (Before vs. After) for all pending edits before approving them.
  • 📊 Dashboard 2.0: Added "Overdue" alerts, "Recent System Logs," and real-time "Monthly Revenue" tracking.
  • 📂 Shortcut Keys: Added Shortcut keys for more accessibility
  • 🔧 Logic Fixes: Optimized Revenue Calculator and Bulk Rental creation flows.
Developer Note:
This update focuses on Security & Transparency. The new logging system ensures no data change goes unnoticed.
